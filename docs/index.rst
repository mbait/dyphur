dyphur — GPU-first rigid-body physics
======================================

**dyphur** is a GPU-first rigid-body physics framework for robotics simulation.
It targets NVIDIA, AMD, and CPU backends via AdaptiveCpp (SYCL 2020), with
sub-millisecond per-frame physics for 1 000+ rigid bodies.
